# Institución Educativa Semillitas del Saber

Sitio web desarrollado para la **Institución Educativa Semillitas del Saber**, con el propósito de brindar información sobre la institución, sus programas académicos, servicios y canales de contacto.

---

## Descripción

Este proyecto consiste en el desarrollo de un sitio web institucional que permite a estudiantes, padres de familia y visitantes conocer la información general de la institución educativa.

El sitio ofrece una navegación sencilla e intuitiva, facilitando el acceso a la oferta académica, noticias, servicios y datos de contacto.

---

## Objetivos

- Presentar la información institucional de manera organizada.
- Dar a conocer los programas académicos ofrecidos.
- Facilitar el acceso a noticias y servicios.
- Mejorar la comunicación entre la institución y la comunidad educativa.
